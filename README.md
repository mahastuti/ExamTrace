# DataSlayer

Proyek deteksi kecurangan saat ujian dari rekaman video.

- `code.ipynb` — notebook proyek.
- `data/train/` — 416 video MOV, dengan 208 video per kelas (`normal` dan `cheat`).
- `data/test/` — 1.515 sekuens gambar JPG.
- `data/sample_submission.csv` — contoh format submission dengan kolom `id` dan `label`.
- `Jawaban FAQ.docx` — dokumen FAQ.
